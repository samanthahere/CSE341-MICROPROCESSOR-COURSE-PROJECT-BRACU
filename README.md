# CSE341-MICROPROCESSOR-COURSE-PROJECT-BRACU
Hospital Management System (EMU8086 Assembly Language Project)
This project is a console-based Hospital Management System developed using Assembly Language in the EMU8086 environment. The system demonstrates low-level programming concepts by managing patient records through different functional modules.

The program provides a menu-driven interface where users can perform multiple operations such as adding patients, viewing records, searching patient information, updating data, deleting records, and handling patient management tasks.

This project focuses on understanding processor-level programming, memory handling, registers, procedures, and interrupt-based input/output operations.

Key Features

Add Patient Record View All Patients Search Patient Information Update Patient Details Delete Patient Record Patient Management Menu System

Technologies Used

Assembly Language (8086) EMU8086 Emulator Interrupt 21h DOS Services Low-Level Memory & Register Operations

This project was developed as part of an academic coursework assignment to strengthen knowledge of Assembly programming, logic building, and system-level computation.
